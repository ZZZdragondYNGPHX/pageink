# 内核补丁

编辑内核为 `@excalidraw/excalidraw@0.18.1`（MIT），由锁文件固定。`scripts/kernel-patch.mjs` 在构建时修改 npm 包的可读发布模块；每个字符串补丁校验精确匹配次数，上游结构变化时构建失败。

## 职责

| 范围 | 实现 |
| --- | --- |
| 输入与压力 | `ink-input.ts` 汇集同一帧的移动和合并采样，一次更新完整坐标与压力，保留同位置的压力变化；支持低延迟指数滑动平均防抖（`data-stabilize`：0 关 / 1 轻 / 2 中，默认轻度防抖 1，开启时同步把完整原始采样坐标保留在 `customData.inkRawPoints`）。`InkCanvas.tsx` 隔离书写时的其他触摸，从完成笔迹派生涂划识别路径。默认等宽，可启用设备压感。 |
| 历史 | `history.ts` / `session.ts` 管理正文跨页和草稿纸独立历史；内核保留编辑快照，跳过内部撤销记录。 |
| 不可变几何 | `element-snapshot.ts` 冻结并共享点与压力；几何编辑创建新数组。冻结点数组的 bounds 使用 WeakMap 缓存，恢复笔迹保留 `lastCommittedPoint`。 |
| 增量提交 | `kernel-journal.ts` 跟踪变更和单调修订号。`InkCanvas.tsx` 跳过无变化提交，`layout.ts` 为单表面直接投影局部坐标。 |
| 空间查询 | `spatial.ts` 建立保守范围索引，复用相同格子的有序候选。跨格、替换、删除和排序变化使缓存失效；场景保留离屏对象及其绑定。 |
| 选择与命中 | 空选择跳过全场景扫描；自由笔起笔跳过变换快照；命中先做空间和范围筛选。 |
| 静态绘制 | 自由笔与拉直荧光线使用完整矢量路径，完成的新笔追加至共享画布；荧光笔在浅色背景下启用 `multiply` 正片叠底混合，不遮挡下方黑字；文字、图片和绑定对象使用上游刷新路径。 |
| 视口复用 | `ink-viewport.ts` 根据可见对象数量和实际绘制耗时自适应决定是否延迟补绘：普通与中等页面实时逐帧重绘无边缘截断；超密场景在缩放/小幅平移时通过 `transform` 复用画布（最大平移阈值 22% 强制刷新，停止 50 ms 后补绘），临时快照覆盖补绘过程。场景修订、尺寸、主题与网格变化立即失效。 |
| 分帧补绘 | 2,000 个以上可见纯自由笔每帧最多绘制 512 笔，CPU 预算约 3 ms；视口变化可中断、恢复或重启补绘，新露出的边缘随补绘恢复。 |
| 缓存释放 | 按各静态画布的可见对象释放离屏缓存，清零底层画布后删除缓存项。同步绘制和卸载取消旧帧；文档几何独立于渲染缓存。 |
| Canvas 尺寸 | CSS 尺寸乘 DPR 后向下取整，再与 backing 尺寸比较，避免浮点尺寸导致反复重置。 |
| 全览与手势 | `viewport.ts` 统一缩放下限，低于 10% 的全览不按 0.1 步进取整。Safari 手势监听限制在各编辑器容器，正文与草稿纸使用独立 `ViewStore`。`ink-gestures.ts` 提供画圈长按套索与一笔成形几何识别。 |
| 局部擦除 | `geometry.ts` 使用单遍胶囊相交算法与 AABB 裁剪，`InkCanvas.tsx` 按 rAF 合并每帧采样；`inkErase` 在整笔擦除跳过全局重排、局部切割优先使用相邻局部 fractional index，保留压力、旋转和撤销；锁定对象跳过擦除。 |
| 资源与样式 | `assets.ts` 管理内嵌资源和 Blob URL；`kernel-css.mjs` 隔离编辑器、portal、动画及字体样式。FontFace 按插件实例登记与释放。 |
| 卡片绑定 | `inkRebind` 在箭头与文字副本上调用上游 `updateBoundElements`；卡片尺寸和绑定连线合为一次正文撤销。 |
| 中文导出 | 本地 Noto CJK 字体与 `export-worker.ts` 组装完整 SVG / PDF 图层。 |

## 集成

`InkCanvas.tsx` 统一处理手写笔记、无边画布和草稿纸。`layout.ts` 投影连续页面坐标，保存时还原页内坐标。完整场景是保存和导出的数据源；视口与缓存仅负责显示。

Markdown 由原生编辑器保存。段落、卡片和属性复用会话、历史及存储服务。模块说明和命令见[开发指南](development.md)。

## 依赖升级与验证

升级内核时逐项迁移补丁并更新匹配校验。相关回归覆盖保存重开、局部与整笔擦除、变换撤销、绑定复制删除、跨页坐标、独立历史、PDF 摘录导出和资源隔离。输入及渲染改动同时运行持续书写与内存压测。

`scripts/embed-assets.mjs` 收集固定版本的字体、PDF Worker、CMap、WASM 和许可，压缩后校验解压字节。安装使用 `main.js`、`manifest.json` 和 `styles.css`；第三方许可内嵌于 `main.js` 的 `pageinkLicenses` 导出，并随安装 ZIP 提供。资源来源见 [PDF runtime assets](pdf-assets.md)。
