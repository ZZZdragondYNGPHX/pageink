# 内核补丁

编辑内核固定为 `@excalidraw/excalidraw@0.18.1`（MIT），来源为 npm 官方包。依赖树由锁文件固定，构建使用 `scripts/kernel-patch.mjs` 对可读发布模块集中修改，而不是手改 `node_modules`。

## 修改的职责

| 修改 | 原因和权威实现 |
| --- | --- |
| 默认等宽与可选真实压力 | 第一个采样即使用明确压力，避免起笔误用内核模拟压力；输入状态由 `InkCanvas.tsx` 管理。 |
| 正文与草稿历史 | 内核不维护第二套未使用撤销栈，`history.ts` / `session.ts` 维护正文跨页与草稿独立历史；内核编辑需要的快照仍保留。 |
| 自由笔不可变快照 | `element-snapshot.ts` 冻结并共享点/压力；内核或操作替换几何时获得新数组，旧历史不变。不省略原始采样。 |
| 完成点往返 | 恢复自由笔时保留已保存的 `lastCommittedPoint`，避免重开后笔端外观变化，而撤销又恢复另一种外观。 |
| 冻结几何边界 | 仅对冻结的点数组使用 WeakMap 缓存 bounds；修改几何会得到新数组，不沿用旧范围。 |
| 增量场景变化 | `kernel-journal.ts` 跟踪变更；追加自由笔、无变化替换等热路径避免重复构建全场景派生结构。 |
| 空间筛选 | `spatial.ts` 为完整场景建立保守范围索引，渲染/命中只投影需要的对象；场景权威、离屏对象、排序、绑定及撤销不因不可见而删除。 |
| 空选择快速返回 | 无选区不全场景扫描选择框及隐藏的样式控件；有选区只处理相关 ID。 |
| 密集静态绘制 | 纯自由笔静态画面可追加已完成新笔；编辑、视口和样式变化使缓存失效。密集场景直接使用上游完整矢量路径，避免每笔一个离屏画布；2,000 个以上可见自由笔分帧补绘，可被新的视口/内容取消，导出不使用屏幕缓存。 |
| 栅格缓存生命周期 | 上游缓存失效前清零两份离屏画布的底层尺寸，并按各静态画布的可见/活动对象释放离开视口的缓存。仅删除 WeakMap 项不能保证及时归还原生/GPU 存储；原始文档对象、点和矢量导出不随缓存释放而删除。切换为同步绘制时取消旧帧并清理补绘状态。 |
| Canvas backing 尺寸 | 将 CSS 浮点宽高乘 DPR 后向下取整再比较，避免小数尺寸使画布每帧重置、缓存被清空。 |
| 大画布全览 | `viewport.ts` 统一缩放下限；fit 低于 10% 时不按 0.1 步进取整。极大范围仍受浮点精度与渲染成本约束。 |
| 真正局部擦 | `geometry.ts` 几何切割，内核一次更新替代逐对象重建；保留压力、旋转及撤销，锁定对象不擦。 |
| 资源及样式隔离 | `assets.ts` 使用随主脚本内嵌的资源与受控 Blob URL，不改上游全局资产变量；`kernel-css.mjs` 作用域覆盖编辑器和独立 portal，并改名动画、界面字体。 |
| 字体生命周期 | 只登记/释放本插件创建的 FontFace；去掉远端字体 fallback，资源来自安装包。旧宿主的既有字体不由本插件清理。 |
| 卡片尺寸与连线 | `inkRebind` 在分离的箭头／文字副本上调用上游 `updateBoundElements`，程序更新卡片尺寸时一并更新绑定连线，随后与卡片合为一次正文撤销。不修改原始笔迹。 |
| 中文导出 | 本地 Noto CJK 字体；SVG 图层经本地 `export-worker.ts` 组装，不依赖远端字体服务。 |

每个字符串补丁检查精确出现次数，未知上游结构直接构建失败。不得删除匹配校验以“修复”升级构建；先理解上游变化，再迁移对应权威职责，避免双历史/双场景系统。

## 集成约定

- `InkCanvas.tsx` 统一处理手写笔记、无边画布与草稿纸输入；`layout.ts` 投影连续页面坐标，保存时还原页内坐标。
- 视口筛选不改变文档权威数据。保存和导出必须保留原始笔迹、压力、附件、绑定与全部页面。
- Markdown 正文由原生编辑器保存；段落、卡片和属性复用现有会话、历史与存储服务。
- 页面操作与草稿纸使用独立历史；原生 Markdown 撤销不由绘写历史代替。

其他模块职责和构建命令见[开发指南](development.md)。

## 升级依赖

补丁按精确出现次数匹配上游结构，不匹配时构建失败。升级编辑内核时应理解并迁移对应职责，不能跳过匹配校验或引入第二套历史与场景数据。

涉及内核的修改需回归保存重开、局部与整笔擦除、几何变换和撤销、绑定复制删除、跨页坐标、正文与草稿纸独立历史、PDF 摘录导出及资源隔离。性能路径修改还需检查持续输入与内存使用。

## 离线资源与许可

`scripts/embed-assets.mjs` 从固定依赖收集字体、PDF Worker、CMap、WASM 和许可，逐个压缩并校验解压后的字节。`src/asset-store.ts` 管理按需读取，`src/assets.ts` 管理 Blob URL 的复用与卸载释放。

社区安装只需 `main.js`、`manifest.json`、`styles.css`。完整第三方许可内嵌于 `main.js` 的 `pageinkLicenses` 导出，并随安装 ZIP 提供。字体保持原始字节和实际版本条款；许可生成器缺项会阻止构建。
