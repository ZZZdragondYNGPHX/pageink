# 混合笔记本：段落与手写

第二阶段将 Markdown 的普通段落和标题放进手写页面或自由画布，并支持段落级笔迹锚定。正文仍由真实 `.md` 和 Obsidian 原生编辑器负责；页面保存可搜索、可导出的纯文本排版投影。它不是富文本编辑器或嵌入式 `MarkdownView`，列表、表格、代码、图片和其他复杂 Markdown 内容继续在原文中使用。

## 使用方式

1. 打开笔记本或自由画布，在书写工具栏选择「文字段落」→「插入文字段落」，选择 Markdown 文件和段落。首次引用没有块标识的段落时，通过原生编辑器添加 `^pi-…`；已有块标识直接复用。
2. 在页面上书写。用选择或圈选工具选中本页笔迹，在「文字段落」中找到对应段落，选择「绑定所选笔迹」。绑定是明确操作，不根据笔迹距离猜测归属。
3. 使用「编辑原文」打开或复用原生编辑器；没有已打开的编辑器时在笔记本旁分屏打开。选中的正文不含块标识，直接替换正文会保留标识。
4. 返回笔记本，选择「更新本页文字」。同一列中后续段落按高度差移动，其绑定笔迹随段落原点平移。超出纸张下沿时扩展该页下方留白，后续纸页整体后移；不会截断文字或笔迹。
5. 可以上移／下移段落、解除笔迹绑定或移除段落。移除段落保留笔迹并解除绑定；所有这些页面操作均可撤销。

段内换字或换行不会变形、拉伸原始笔迹，也不会推断批注指向了哪个词。更新后要检查段内批注位置。复杂段落内的语义锚定、自动分页与逐行批注跟随是后续能力。

## 保存、历史与身份

- `.inknote` 继续使用现有 `schema: 1`；普通 Excalidraw `text` 元素的 `customData.pageinkText` 保存版本、源路径、原生块标识、快照资源 ID 与排版宽度。投影默认锁定，通过段落面板管理。
- `freedraw.customData.pageinkAnchor` 只保存所属段落元素 ID。移动段落仅改变笔迹 `x/y`；原始 `points`、`pressures`、角度和 `lastCommittedPoint` 保留。
- 段落元素 ID 在更新后不变；复制整页或一组内容会重映射复制集合内的锚点。单独复制笔迹会解除其锚点。跨页场景分区保持笔迹与所属段落在同页。
- Markdown 的正文编辑、块标识写入及撤销归原生编辑器所有。绘图会话只记录投影、锚点和布局的撤销；文字更新与页面留白变更合为一次正文撤销，不回写 `.md`，不改变草稿纸历史。
- 更新前先读取全部来源。段落／标识缺失、重复或改为不支持的复杂块时，整页拒绝更新，保留当前投影与笔迹。异步操作会检查目标页面、视图生命周期和段落版本。
- 源文件改名后，旧路径不存在时按唯一原生块标识查找；多个候选时停止，避免引用错误原件。自定义引用不会自动进入 Obsidian 原生反向链接索引。
- 每次成功读取来源后，将完整 UTF-8 Markdown 原件按 SHA-256 存为独立不可变资源。更新仅新建资源，旧资源仍可用于撤销、恢复和备份。这些资源不交给内核的图片文件加载器。

## 导出与恢复

页面文字使用正常绘图文字对象，与笔迹共用屏幕、搜索、PNG、区域预览和矢量 PDF 导出路径。导出读取完整对象集合，不依赖当前视口。

`.inkpack` 包含当前投影、所有原始笔迹、草稿、图片、必要 PDF，以及保留的完整 Markdown 来源快照。快照对应插入／更新时的原文，导出不会隐式刷新页面。原文被删除后，快照仍可打包；快照资源缺失或引用损坏时拒绝打包。

恢复时，每份 Markdown 快照产生不可变资源与独立可编辑 `.md`，引用路径指向新的 `.md`。同一快照的多个引用共享恢复原件；同一源文件的不同快照分别恢复，保留各自版本。恢复后编辑 `.md` 不会污染不可变快照，不会覆盖库内原文件。Markdown 里链接的外部附件、其他笔记和第三方插件依赖不会递归打包。

## 源码边界

| 文件 | 职责 |
| --- | --- |
| `src/mixed.ts` | 来源与锚点类型、普通段落识别、重排和锚点身份操作。 |
| `src/mixed-host.ts` | 原生来源选择、块标识、编辑器复用、保存和改名查找。 |
| `src/mixed-render.ts` | 不可变原文快照和稳定 ID 的文字投影。 |
| `src/MixedPanel.tsx` | 当前页段落、绑定、原文编辑和顺序操作。 |
| `src/Workspace.tsx` | 将异步来源读取、页面变更、反馈与现有工作区连接。 |
| `src/session.ts` / `src/history.ts` | 内容与布局合并历史，保留原文及草稿的独立历史。 |
| `src/archive.ts` | 校验、完整打包、独立恢复原件和快照。 |

本阶段没有新增内核字符串补丁，没有构造私有 Markdown 编辑器，没有改变 `.md` 的默认处理器。
