# PageInk 0.1.2

2026-11-09。此版本整合原生 Markdown、分页绘写与无边画布，并打磨笔记库、创建入口和文案。插件 ID 保持 `pageink`，最低 Obsidian 版本保持 `1.12.7`。

## 更新内容

- **文笺、手札、长卷**：分别对应普通 `.md` 文件、分页绘写、无边画布。新建入口保留明确说明，窄屏也能区分；既有文件和链接无需迁移。
- **更短的新建流程**：笔记库一键创建，名称与纸张按需展开；继续提供 PDF 批注、设备导入和完整备份恢复。
- **统一笔记库**：按类型筛选，默认搜索名称、正文、属性、画布文字与 PDF 文本；支持今日记录和快速打开。
- **原生文字与绘写互通**：插入手写区域预览、文字段落与画布卡片，保留原文链接、原始笔迹及完整可编辑备份。
- **操作反馈与键盘**：工具方向键导航、单选控件键盘操作、Escape 返回焦点、错误重试对应动作；阻止重复创建和过期搜索／跳转抢回焦点。
- **文案与布局**：统一类型名、属性和复制目标；改善深浅主题、窄屏层次与保存状态。

## 安装

从 [0.1.2 发布页](https://github.com/ZZZdragondYNGPHX/pageink/releases/tag/0.1.2) 下载 `pageink-0.1.2.zip`，将其中 `pageink/` 放入笔记库的 `.obsidian/plugins/`，然后启用插件。也可下载 `main.js`、`manifest.json` 和 `styles.css` 三个附件，放入 `.obsidian/plugins/pageink/`。

社区目录收录前可手动安装。GitHub 版本发布与社区市场上架是两个独立步骤，收录状态以 [Obsidian Community](https://community.obsidian.md/) 为准。

## 已知边界

- 当前界面为简体中文。iPad、Apple Pencil 与实际同步服务未进行本轮真机验证。
- 手写与无文字层的扫描件暂不支持 OCR 搜索。
- `main.js` 约 46 MB，包含离线字体、PDF Worker、解码资源和第三方许可；无需账号或运行时下载。
- 极大画布和复杂 PDF 仍受设备内存与渲染成本约束，不承诺所有场景 60 FPS。
