# 画板内容卡片

自由画布的「画板卡片」把原生 Markdown 段落和手写笔记本区域放在同一张画板上。卡片使用现有绘图对象、原生绑定连线与分组，继续走正文保存、撤销、搜索和导出路径。

## 使用

- **文字卡片**：在画板工具栏点「画板卡片 → 插入文字卡片」，选择原生笔记及段落。用选择工具双击卡片，或选中后按 Enter，在卡片位置打开段落编辑框；「保存到原文」或 Ctrl/⌘ + Enter 提交到原生 Markdown 编辑器。块 ID 保留。修改后，同一画板中引用这段原文的文字卡片一起更新。
- **手写卡片**：先在手写笔记本中圈选区域并加书签，再从「插入手写卡片」选择笔记本与区域。用选择工具双击卡片或点「打开手写原件」返回原区域书写，回到画板后点「更新卡片」。
- **连接与组合**：用选择工具配合 Shift 选择两张卡片，在卡片面板点「连接所选卡片」。框选多个对象后可「组合所选」一起移动；「取消组合」移除最外层组合。连线也可用现有箭头工具绘制、调整。
- **来源变化**：外部修改后显式更新卡片。手写原件删除或需要回到引用时的版本时，点「恢复引用时的原件」，另存完整笔记本，并让这张卡片关联到恢复副本。不会覆盖现存原件。

## 正文与撤销

原位编辑框是临时段落草稿，支持一个普通段落或 ATX 标题，以纯文本投影。列表、表格、代码、多段落和富文本排版继续在原生笔记中编辑。提交前比较完整原文；如果原文在其他位置变化，拒绝覆盖并保留草稿，供复制或放弃后重新打开。失焦不自动提交；修改过的草稿需明确点击「放弃草稿」关闭。

最终修改只通过公开 `MarkdownView.editor.replaceRange()` 与 `MarkdownView.save()` 提交，必要时保留一个后台原生编辑标签。没有在卡片中重建 MarkdownView、重挂载原生编辑器 DOM 或修改 Obsidian 私有 Canvas。

草稿输入使用文本框本身的编辑历史。提交后的 Markdown 历史归原生编辑器；卡片更新、位置、大小、连线和分组归绘图历史。画板撤销不会撤销已提交的原文。关闭画板前应先提交或复制未提交草稿，草稿不进入文档备份。其他画板及混合笔记本中的引用通过各自的更新操作载入原文。

## 存储与恢复

入口继续使用 `.inknote` 的 `schema: 1`。新字段在 Excalidraw `customData` 内，旧文档无需迁移：

- 文字卡片：矩形根对象 `pageinkCard = { version: 1, kind: 'text' }`，绑定的锁定文字对象继续使用 `pageinkText`。`containerId`、`boundElements` 与 `groupIds` 由现有复制、分区和保存逻辑处理。
- 手写卡片：图片对象 `pageinkCard = { version: 1, kind: 'ink', path, document, page, region, title, archiveAsset }`。`fileId` 指向区域 PNG 预览；`archiveAsset` 指向引用时完整的 `.inkpack` 字节，MIME 为 `application/x-pageink`。
- 连线与分组：使用内核原生 `startBinding` / `endBinding` 与 `groupIds`。程序更新卡片尺寸时，通过集中补丁中的 `inkRebind` 调用上游绑定计算，处理连线端点；与卡片文字合为一次绘图撤销。

手写预览长边至多 1600 像素。阅读 PDF / PNG 中手写卡片使用这张栅格预览；完整原始笔迹、压力、完成点、页面、附件、草稿纸和所需 PDF 保存在原件备份中，可恢复后继续编辑。文字卡片继续走文字导出路径。

打包画板时包括所有保留的 Markdown 快照、手写预览和完整原件备份。恢复画板后，Markdown 快照另存为可编辑 `.md`；手写卡片保留共享来源 ID，也可按需从内嵌备份恢复独立原件。复制卡片产生新对象身份，但继续引用同一来源。普通副本、冲突副本和历史恢复均保留这些资产。

更新手写卡片会保留旧原件备份，以支持撤销和完整导出，因此资源可能明显大于预览图片。嵌套备份按已保存字节收集，不递归追踪其他活跃文档；Markdown 中链接的其他笔记及附件仍不递归收集。手写卡片插入入口限手写笔记本的区域，避免把整张画板作为可递归展开的实时节点。

## 代码边界与验证

`cards.ts` 定义与验证卡片；`cards-render.ts` 生成文字／图片投影与绑定连线；`cards-host.ts` 负责来源选择、完整备份、预览和恢复；`CardsPanel.tsx` 提供卡片列表与原位草稿；`Workspace.tsx` 将这些操作合入现有会话。

自动检查：`npm run typecheck`、`npm test`、`npm run build`。隔离宿主脚本 `dev/cards-workflows.mjs` 检查真实鼠标拖动、原位编辑、冲突草稿、连线分组、复制与撤销、手写原件删除后恢复，以及 PDF、完整包与重开。宿主脚本串行运行；报告包含所测构建 SHA-256。

iPad/Pencil、实际中文输入法组合过程、真实跨设备同步与大规模卡片压力负载尚未验证。
