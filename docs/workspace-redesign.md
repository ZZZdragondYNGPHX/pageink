# 工作区改版

本次改版将两种记录方式统一命名为「笔记本」和「自由画布」，同时统一「草稿纸」「圈选」「摘录」「纸张与页边距」「历史版本」「可编辑备份」等入口。保持 `.inknote`、原始采样点、附件、引用协议和可编辑备份兼容。

## 设计依据与素材

| 来源 | 应用到 PageInk 的部分 |
| --- | --- |
| [Apple Freeform 官方使用说明及界面](https://support.apple.com/en-gb/guide/ipad/ipad9c59637d/26/ipados/26) | 自由画布的浮动工具栏、点阵背景、左下角缩放与保存视野。视野书签沿用 PageInk 的稳定区域引用。 |
| [Goodnotes 官方界面说明](https://support.goodnotes.com/hc/en-us/articles/13682253498767-Improved-User-Interface) | 将文档操作与书写工具分开；常用工具位置稳定，再次点击当前工具展开设置；页面缩略图与直接跳页。 |
| [Notability 官方入门说明](https://support.gingerlabs.com/en-us/articles/16300108-getting-started-with-notability) | 快速切换书写工具与颜色，并记住各工具的样式设置。 |
| [Lucide 图标与许可](https://lucide.dev/license) | 直接使用固定版本 `lucide-react@1.70.0` 的 SVG，统一线宽和比例；继承宿主主题色。 |

参考产品的界面图仅用于设计比对。分发的图标素材来自 Lucide；新建入口的纸张、便签和连线示意由 CSS 绘制。Lucide ISC 及所含 Feather MIT 原文随构建许可清单、安装包与 `main.js` 内嵌许可一起保留。应用运行时不请求这些网站。

界面使用 Obsidian 的字体和主题变量，蓝色工具选中态、纸张与桌面分层。正文让出尽可能多的可写区域，设置只随当前工具展开。窄窗口保留历史按钮，并通过「更多工具」访问全部工具。

## 工作流程

- 新建窗口直接选择笔记本或自由画布，名称可省略；PDF 批注、设备导入和备份恢复在同一入口。
- 笔记本连续展示各页，顶部可切换阅读与书写；左侧缩略图和底部页码都可跳页，底部可直接添加页面。
- 自由画布使用浮动工具栏，可一键全览、保存当前视野，或框选区域加书签。
- PDF 摘录自动放入草稿纸；复制到正文直接落在当前视野，可拖动调整。正文和草稿纸各自撤销，草稿纸可拖动或用键盘移动、调整大小。
- 整页 PDF 文字既可直接复制，也可在原文面板中选取一段。搜索涵盖 PDF 文字、文本框和书签。
- 导出支持完整正文 PDF、当前页 PDF/PNG、自由画布全部内容和选区。可编辑备份包含正文、草稿纸、附件和原 PDF。

## 架构与验证方式

输入由 `InkCanvas.tsx` 统一处理；`layout.ts` 将页内数据投影到连续场景，并在保存时还原页内坐标。纸张/PDF 绘制、视野、工具栏、侧栏、草稿纸和宿主服务分别独立。内核补丁约束继续见 [内核边界](kernel-patches.md)。

```bash
npm run typecheck
npm test
npm run build
node dev/shots.mjs
node dev/workflows.mjs
```

后两项需要可运行的 Linux Obsidian AppImage 和图形会话，通过 `OBSIDIAN_APPIMAGE` 指定程序。脚本只创建仓库中的 `.test-vault/` 和临时宿主配置；截图与报告写入被 Git 忽略的 `artifacts/`。测试失败会返回非零状态。

`shots.mjs` 覆盖新建、连续页、跨页撤销/重做、PDF、圈选、草稿纸、导出菜单、自由画布与窄窗口；`workflows.mjs` 验证原始笔迹保存重开、阅读模式、PDF 文字与搜索、摘录回填、独立撤销、完整导出和恢复、书签、深色主题与减少动态效果。
