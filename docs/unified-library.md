# 统一笔记库：日常入口、搜索与属性

第四阶段把前三阶段的文字、混合笔记本和画板内容接到同一个日常入口。既定四阶段的实现范围到此闭合；卡片内富文本排版、直接编辑手写卡片、手写 OCR、逐行批注锚定和实时协作不属于本轮交付。

## 日常入口

- 侧栏的笔记本图标、命令「打开笔记库」或「搜索整个笔记库」打开同一笔记库，并聚焦搜索框。原生 Markdown 工具栏与手写工作区都能返回这里。
- 「新建笔记」继续选择普通文字、手写笔记本或自由画布。库内文件可按类型筛选，以最近修改排序，每批显示 60 个结果。
- 「快速打开…」或同名命令按路径选择文字、手写文档或 PDF，复用已打开的标签。
- 「今日记录」或「打开今日记录」使用设备的本地日期，打开 `PageInk Daily/YYYY-MM-DD.md`。不存在时创建普通 Markdown；存在时直接打开，多次点击共用同一个创建任务，不覆盖已有内容。

今日记录使用上述固定目录，不读取 Obsidian 核心 Daily Notes 的私有设置，也不迁移原有日记或套用其模板。笔记库不会替换宿主启动布局或禁用核心插件。可自行给命令配置快捷键。

## 搜索范围与结果

默认搜索名称、路径、正文与属性；取消「搜索正文与属性」后仅筛选名称和路径。关键词不区分大小写，以空白分隔，多个关键词必须在同一份文档内全部出现，可以分别位于名称、属性或不同内容位置。不提供原生搜索的高级查询语法。

| 来源 | 搜索内容 | 打开结果 |
| --- | --- | --- |
| 普通 Markdown | 当前原生编辑器内容，或磁盘 Markdown（包括 frontmatter） | 原生编辑模式，选中匹配行 |
| 手写笔记本／画板 | 清单标题、属性、区域书签、正文页面中的文本对象和共享段落投影 | 文档、页面、书签或对象区域 |
| PDF | 原 PDF 的可提取文本层，包括批注笔记所关联的 PDF | 原生 PDF 页码，或批注笔记的对应页面 |

每个文件显示一个结果和内容摘录，优先定位包含更多关键词的已读取片段；关键词分散在不同位置时定位其中一处。文字投影按当前画面保存的内容检索，不隐式刷新其 Markdown 来源。同一段原文及其画板投影可以分别成为结果。

不识别手写笔迹、扫描图像或图片中的文字；不递归检索卡片内嵌原件包、历史版本、不可变 Markdown 快照或草稿纸。原生 Obsidian `.canvas` 文件继续由宿主管理，未转换为 PageInk 画板。损坏的入口在无查询时仍列出，搜索读取失败会显示具体文件与原因；资源缺失不被当成空文档。

## 读取、取消与边界

`library-search.ts` 管理关键词匹配、进度、摘录与取消，`library-search-host.ts` 隔离宿主读取，`Library.tsx` 仅管理界面。输入有 250ms 防抖；切换查询、文件类型或离开视图时取消旧任务，旧结果不能覆盖新结果。也可点击「停止搜索」，此时明确标记结果不完整，并保留已找到的结果；「重新搜索」重试。

按文件串行读取，绘图按页读取，PDF 文本按页提取，页面之间让出主线程。找到全部关键词后可以结束该文件的读取。PDF 资源在完成、失败或取消后释放；正在执行的底层文件读取／单页提取需返回后才检查取消。打开的 Markdown 优先使用原生编辑器；绘图使用会话已提交状态，尚未结束的一笔不会参与搜索。

不写入持久正文索引，不另存笔记内容。大库仍需要逐文件搜索；第一次读取大型 PDF 的内存与时间由原文件体积决定。没有宣称通过大型库压力或跨设备同步测试。

## 属性

笔记库每行的属性按钮、Markdown 工具栏「笔记属性」、绘图「更多 → 笔记属性…」、文件菜单以及命令「编辑笔记属性…」使用同一表单。支持文本、数字、布尔值和字符串列表；复杂属性只读保留。只保存用户改过的键，保存前检查同一键是否发生并发变化，失败保留草稿。

Markdown 属性使用公开 `FileManager.processFrontMatter`；原生编辑器继续拥有正文。手写属性位于 `.inknote` 的可选 `properties` 字段，沿用会话保存、冲突副本、历史版本与完整备份。属性保存不加入绘图几何撤销栈。详细数据和冲突规则见 [笔记属性](note-properties.md)。

公开 API 依据：[Obsidian API](https://github.com/obsidianmd/obsidian-api)、[FileManager.processFrontMatter](https://github.com/obsidianmd/obsidian-api/blob/master/_autodocs/api-reference/vault.md)、[原生 Editor](https://github.com/obsidianmd/obsidian-api/blob/master/_autodocs/api-reference/editor.md)。没有新增第三方依赖或本阶段内核补丁。
